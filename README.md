# Hamzah Musamih — engineering portfolio

Static site (HTML, CSS, a little JavaScript). No build step.

- `index.html` — all content
- `assets/css/style.css` — styles
- `assets/js/main.js` — scroll reveals, timeline line, lightbox
- `assets/img/` — project images (WebP)
- `assets/models/` — 3D models (GLB) shown with Google's `<model-viewer>`

To add a 3D model: export from SolidWorks as STEP or GLB, drop the GLB in `assets/models/`, and copy the `<figure class="viewer">` block from the electrolyzer section.

Hosting: GitHub Pages, deploy from the `main` branch root.
